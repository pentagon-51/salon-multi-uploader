미용실 무료 배포 · 3분 시작 안내

미용실 멀티업로더 — 처음 시작 3단계 안내

복잡한 설정 없이 아래 3단계만 순서대로 따라하시면 10개 SNS 동시 업로드를 바로 시작할 수 있습니다.

1단계

원클릭 자동 설치 (Windows / Mac)

⚠️ 먼저 다운로드한 ZIP 파일의 압축을 완전히 풀어주세요! (압축 파일 안에서 [실행]을 누르면 설치되지 않습니다. 팝업이 뜨면 반드시 [압축 풀기]를 눌러주세요.)
사용 중인 PC에 맞는 설치 파일을 실행하세요. 필요한 프로그램이 자동으로 설치됩니다.

🪟 Windows (윈도우 PC)

  • 압축을 푼 폴더 안의 1-1. 윈도우 최초설치.bat을 더블클릭하세요.
  • 설치가 끝나면 바탕화면에 「미용실 멀티업로더」 아이콘이 자동 생성되고 프로그램이 바로 열립니다.

🍎 Mac (맥북 · 아이맥)

  • 압축을 푼 폴더 안의 2-1. 맥북 최초설치.command를 실행하세요.
  • 보안 경고가 뜨면 파일에 우클릭 ➔ 열기 ➔ 열기를 누르면 정상 실행됩니다.
💡 처음 설치할 때는 2~5분 정도 걸릴 수 있습니다. 완료 메시지가 나올 때까지 잠시만 기다려 주세요.
2단계

1~3단계 초기 설정 따라하기

프로그램이 처음 열리면 안내 화면이 자동으로 뜨며, 입력한 내용은 실시간으로 자동 저장됩니다.
  • 1단계 (플랫폼 선택 · 로그인): 사용할 SNS만 골라 켜고, 안 켜진 SNS 창에 처음 한 번만 로그인하면 다음부터 자동으로 유지됩니다. (유튜브 API 설정 포함)
  • 2단계 (기본정보 · 프로필): 매장명·지역 기반 해시태그(최대 3개)·디자이너·인포크링크·블로그 게시판을 입력하면 아래 카드가 실시간 완성됩니다. 공용 SNS 소개글은 각 앱의 바이오(소개) 칸에, 예약 링크는 [웹사이트/링크] 칸(또는 소개글 맨 아래)에 원클릭 복사해 붙여넣고 블로그 '오시는 길' 고정글을 세팅합니다.
  • 3단계 (본문 프롬프트 · 10초 체험): 입력한 지역 기반 해시태그(최대 3개)와 황금 비율 해시태그 규칙이 자동 반영된 기본 표준 또는 내 말투 스타일 프롬프트를 복사하고 미리보기를 바로 체험합니다.
3단계

매일 1클릭 실행

설치가 끝나면 매일 클릭 한 번으로 바로 사용할 수 있습니다.
  • Windows: 바탕화면 「미용실 멀티업로더」 아이콘(또는 1-2. 윈도우 프로그램 실행.bat) 더블클릭
  • Mac: 폴더 안의 2-2. 맥북 프로그램 실행.command 더블클릭
  • 영상 첨부 ➔ 글 붙여넣기 ➔ [✨ 미리보기 생성] ➔ [🚀 일괄 업로드] 순서로 간편하게 완료됩니다.

🔄 원클릭 자동 업데이트 사용법

  • 프로그램을 열면 새 버전을 자동 확인하며, 상단 [🔄 업데이트 확인] 버튼으로 언제든 확인할 수 있습니다.
  • 새 버전 안내가 뜨면 [🚀 원클릭 업데이트] 버튼만 누르세요.
  • 로그인 정보, 매장 설정, 아직 올리지 않은 영상은 그대로 안전하게 유지되며 프로그램 기능만 최신으로 바뀝니다.
  • 완료 안내가 뜨면 실행 파일(Windows: 1-2. 윈도우 프로그램 실행.bat / Mac: 2-2. 맥북 프로그램 실행.command)을 다시 열어주세요.

📜 라이선스 및 무료 이용 안내 (LICENSE.txt)

  • 허용: 개인 헤어디자이너 및 미용실 매장의 무료 사용, 제작자 표기·공식 링크를 유지한 동료 추천
  • 금지: 유료 판매·임대, 사전 동의 없는 유료 강의·컨설팅·대행 상품 끼워팔기, 제작자 표기·공식 링크 삭제 후 재배포
  • 면책: 있는 그대로(AS-IS) 무료 제공되며, 외부 SNS 화면 개편 시 일시적 오류가 발생할 수 있습니다. 계정 및 게시물 책임은 사용자 본인에게 있습니다.
🛟 혹시 설치·실행 중 막히셨나요? (필요할 때만 펼쳐서 확인하세요)
🛡️ 혹시 V3·윈도우 보안에서 차단 알림이 떴나요?

1) 파란색 「Windows의 PC 보호」 창이 뜰 때

창 왼쪽의 [추가 정보] 글자를 누른 뒤 아래에 나타나는 [실행] 버튼을 클릭하면 정상 실행됩니다.

2) 안랩 V3에서 차단 또는 경고가 뜰 때

V3 실행 ➔ 우측 상단 톱니바퀴(환경설정) ➔ 검사 설정 ➔ 검사 예외 대상 ➔ [추가] 버튼을 눌러 프로그램 폴더를 등록하세요.

3) Windows Defender(윈도우 보안)에서 차단될 때

Windows 보안 ➔ 바이러스 및 위협 방지 ➔ 설정 관리 ➔ 제외 항목 추가 또는 제거 ➔ [제외 사항 추가] ➔ 폴더 선택 ➔ 프로그램 폴더를 등록하세요.

⌨️ 자동 설치가 막혔을 때 비상용 수동 명령어 복사

키보드 Win + R ➔ cmd 입력 후 Enter를 눌러 검은 창(명령 프롬프트)을 열고, 아래 명령어를 복사해 붙여넣은 뒤 Enter를 누르세요.

① 필수 파이썬 패키지 설치 
python -m pip install --upgrade pip playwright opencv-python pillow pyperclip google-api-python-client google-auth-oauthlib
② 자동화 브라우저(Chromium) 엔진 설치 
python -m playwright install chromium
⚡ 한 번에 실행하기 (① + ② 통합 명령어) 
python -m pip install --upgrade pip playwright opencv-python pillow pyperclip google-api-python-client google-auth-oauthlib && python -m playwright install chromium
