오픈소스 미용실 전용 · 오프라인 시작 안내서

헤어살롱 SNS 멀티 업로더 — 처음 시작 3단계 안내

복잡한 개발 지식 없이 아래 3단계만 순서대로 따라하시면 9개 SNS 동시 업로드를 바로 시작할 수 있습니다.

1단계

원클릭 자동 설치

폴더 안의 1_최초설치_자동인스톨.bat 파일을 더블클릭하세요.
  • 실행 환경과 필수 프로그램, 자동화 브라우저 엔진이 순서대로 자동 설치됩니다.
  • 설치가 끝나면 바탕화면에 전용 아이콘이 적용된 「헤어살롱 SNS 업로더」 바로가기가 자동 생성됩니다.
  • 설치가 완료되면 이 안내서와 설치 파일은 _설치완료_보관함 폴더로 자동 정리된 뒤 프로그램이 바로 열립니다.
💡 설치 도중 2~5분 정도 소요될 수 있습니다. 창이 닫히고 대시보드가 열릴 때까지 잠시만 기다려 주세요.
2단계

0~4단계 온보딩 마법사 따라하기

프로그램이 처음 열리면 [📘 초기 설정 & 온보딩 마법사]가 자동으로 나타나며, 입력할 때마다 자동 임시 저장됩니다.
  • 0~1단계 (플랫폼 선택 · 기본정보): 당장 쓸 플랫폼만 고르고, 본인 매장명(스마트플레이스 검색명과 동일) · 대표 지역 키워드 · 디자이너 이름 · 인포크링크(가이드 팝업 제공) · 자동 업로드할 블로그 게시판 목록을 입력합니다.
  • 2단계 (프로필 · 블로그 오시는 길): 자동 생성되는 SNS 프로필 바이오와 네이버 블로그 '오시는 길' 고정글 초안을 클릭 한 번으로 복사해 붙여넣습니다.
  • 3단계 (1창 통합 로그인 · 유튜브 API): 선택한 플랫폼의 미로그인 탭이 전용 크롬 1창에 한 번에 열립니다. 로그인 후 창 우측 상단 X로 닫으면 전용 프로필(auth_data/chrome_profile)에 영구 저장됩니다.
  • 4단계 (본문뽑기 프롬프트 & 10초 체험): [기본 표준으로 바로 쓰기] 또는 [내 글·기존 프롬프트로 내 스타일 입히기] 2가지 모드 중 원하는 방식으로 전용 마스터 프롬프트를 복사하고, 별도 AI API 키 없이 순수 파이썬 변환 엔진으로 미리보기를 바로 체험합니다.
3단계

매일 1클릭 실행

다음부터는 아주 간단합니다.
  • 바탕화면에 생성된 「헤어살롱 SNS 업로더」 아이콘(또는 폴더 안의 2_프로그램_실행.bat)만 더블클릭하세요.
  • 실행할 때마다 최신 버전이 있으면 자동 업데이트된 뒤 바로 프로그램이 열립니다. (개인 로그인·프로필 데이터는 auth_data/에 안전하게 분리 보호됩니다.)
  • 영상 첨부 ➔ 시술 메모 입력 ➔ [✨ 미리보기 생성] ➔ [🚀 일괄 업로드] 순서로 간편하게 완료됩니다.

🔄 원클릭 자동 업데이트 사용법

  • 프로그램 실행 시 최신 버전을 자동 확인하며, 언제든 대시보드 상단 [🔄 업데이트 확인] 버튼을 눌러 수동 확인할 수 있습니다.
  • 새 버전이 있으면 상단 파란 배너의 [🚀 원클릭 업데이트] 버튼만 누르세요.
  • 개인 데이터 100% 보호: auth_data/(로그인·크롬 프로필·설정·유튜브 토큰)와 로컬 미디어 파일은 절대 건드리지 않고 순수 코드만 안전하게 갱신됩니다.
  • 업데이트 완료 안내가 뜨면 실행 파일(Mac: 서버재시작.command / Windows: 2_프로그램_실행.bat)을 다시 실행해 주세요.

📜 라이선스 및 무료 이용 안내 (LICENSE.txt)

  • 허용: 개인 헤어디자이너 및 미용실 매장의 무료 사용, 제작자 표기·공식 링크를 유지한 동료 추천
  • 금지: 유료 판매·임대, 사전 동의 없는 유료 강의·컨설팅·대행 상품 끼워팔기, 제작자 표기·공식 링크 삭제 후 재배포
  • 면책: 있는 그대로(AS-IS) 무료 제공되며, 외부 SNS 화면 개편 시 일시적 오류가 발생할 수 있습니다. 계정 및 게시물 책임은 사용자 본인에게 있습니다.
🛟 혹시 설치·실행 중 막히셨나요? (필요할 때만 펼쳐서 확인하세요)
🛡️ 혹시 V3·윈도우 보안에서 차단 알림이 떴나요?

1) 파란색 「Windows의 PC 보호」 창이 뜰 때

창 왼쪽의 [추가 정보] 글자를 누른 뒤 아래에 나타나는 [실행] 버튼을 클릭하면 정상 실행됩니다.

2) 안랩 V3에서 차단 또는 경고가 뜰 때

V3 실행 ➔ 우측 상단 톱니바퀴(환경설정) ➔ 검사 설정 ➔ 검사 예외 대상 ➔ [추가] 버튼을 눌러 sns_auto 폴더를 등록하세요.

3) Windows Defender(윈도우 보안)에서 차단될 때

Windows 보안 ➔ 바이러스 및 위협 방지 ➔ 설정 관리 ➔ 제외 항목 추가 또는 제거 ➔ [제외 사항 추가] ➔ 폴더 선택 ➔ sns_auto 폴더를 등록하세요.

⌨️ 자동 설치가 막혔을 때 비상용 수동 명령어 복사

키보드 Win + R ➔ cmd 입력 후 Enter를 눌러 검은 창(명령 프롬프트)을 열고, 아래 명령어를 복사해 붙여넣은 뒤 Enter를 누르세요.

① 필수 파이썬 패키지 설치 
python -m pip install --upgrade pip playwright opencv-python pillow pyperclip google-api-python-client google-auth-oauthlib
② 자동화 브라우저(Chromium) 엔진 설치 
python -m playwright install chromium
⚡ 한 번에 실행하기 (① + ② 통합 명령어) 
python -m pip install --upgrade pip playwright opencv-python pillow pyperclip google-api-python-client google-auth-oauthlib && python -m playwright install chromium
헤어살롱 SNS 멀티 업로더 · 무료 공개 배포 (모든 매장·개인 정보는 내 PC의 auth_data/에만 보관됩니다)
✅ 명령어가 클립보드에 복사되었습니다!
